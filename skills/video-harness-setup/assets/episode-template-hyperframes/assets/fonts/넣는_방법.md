# 폰트 넣는 방법

이 폴더는 비어 있어도 된다. 지금 `index.html`의 `@font-face`는 파일 없이 아래 순서로만 글꼴을 찾는다.

1. 같은 이름의 설치된 시스템 폰트 — `local("Pretendard")`, `local("Paperlogy")`
2. 그것도 없으면 한글을 지원하는 시스템 폰트 — `local("Apple SD Gothic Neo")`(macOS), `local("Malgun Gothic")`(Windows)

`src`에 존재하지 않는 파일을 가리키는 `url(...)`을 넣으면 `hyperframes check`가 404로 실패한다(런타임 오류, 경고가 아니다) — 그래서 이 템플릿에는 기본으로 `url(...)`이 없다.

채널 라이선스가 있는 폰트 파일(`Pretendard-Bold.otf`, `Paperlogy-Black.ttf` 등)을 구했으면:

1. 그 파일을 이 폴더에 넣는다.
2. `index.html`의 해당 `@font-face`의 `src` 맨 앞에 `url("assets/fonts/<파일명>"),`를 직접 추가한다(자동으로 인식되지 않는다).
3. `npx --yes hyperframes@0.8.43 check`를 다시 돌려 새 파일이 정상적으로 로드되는지 확인한다.

파일명과 두께(weight)는 채널의 `frame.md`(`typography.caption`, `typography.title`) 값과 맞춘다 — 폰트가 바뀌어도 `family`/`weight` 값은 `tokens.css`(`var(--f-*)`, `var(--f-*-w)`)에서 온다.
