# 프로젝트 폰트 넣는 방법

기본값은 아무 폰트 파일도 넣지 않는다. `theme.ts`의 `typography.*Family` 값은
시스템에 설치된 한글 폰트("Apple SD Gothic Neo", "Malgun Gothic" 등)로 자동
대체된다.

프로젝트 전용 폰트 파일(`.woff2`, `.ttf` 등)을 쓰고 싶으면:

1. 폰트 파일을 이 폴더(`public/`)에 넣는다. 예: `public/Pretendard-Bold.woff2`
2. `src/Episode.tsx` 등 컴포넌트가 렌더되기 전에 `@remotion/fonts`의
   `loadFont()`로 그 파일을 로드한다.

```tsx
import { loadFont } from "@remotion/fonts";
import { staticFile } from "remotion";
import { theme } from "./theme";

await loadFont({
  family: theme.typography.captionFamily,
  url: staticFile("Pretendard-Bold.woff2"),
  weight: String(theme.typography.captionWeight),
});
```

`@remotion/fonts`는 이 템플릿의 기본 의존성이 아니다(실제로 로컬 폰트 파일을
쓰는 채널만 필요하므로). 위 코드를 쓰기로 했으면 먼저 설치한다.

```bash
npm install @remotion/fonts@4.0.526 --save-exact
```

**중요**: 폰트 패밀리 이름과 굵기는 여기서 하드코딩하지 않고 위 예시처럼
`theme.ts`(`theme.typography.captionFamily` 등)에서 그대로 가져와 쓴다.
`frame.md`의 `typography` 값을 바꾸면 `build_tokens.py`가 `theme.ts`를 다시
만들어 주므로, 폰트 파일 이름만 그 값과 맞으면 회차마다 코드를 고치지 않아도
된다.
