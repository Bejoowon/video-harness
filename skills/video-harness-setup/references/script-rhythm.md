# 대본 운율 — 읽으면 리듬이 느껴지는 내레이션

작업 규칙 `rules.script_rhythm`이 `meter`(기본)일 때 에이전트가 따르는 규칙이다. `free`면 이 문서는 읽지 않아도 된다. 같은 규칙이 작업 공간의 `AGENTS.md` "대본 쓰기" 절과 채널의 `02_기획과자막/_양식/대본_양식.md`에도 들어간다.

## 규칙

- 내레이션 대본은 읽었을 때 운율이 느껴지게 쓴다. 한 줄을 **마디**(한 호흡에 읽는 덩어리, 보통 한두 어절)로 나누고, 마디는 **3~4음절이 기본, 5음절까지 허용**한다.
- 한 줄은 **네 마디가 기본**이다(`3/4/4/3`, `4/4/4/3`, `3/4/3/4`, `4/4/4/4` …). 짧게 끊을 때는 **두 마디**(`3/4`, `4/4`, `4/5`)도 좋다. 세 마디도 허용한다.
- **뜻이 먼저다.** 운율을 맞추려고 말이 어색해지거나 사실이 바뀌면 안 된다. 고유명사·숫자·인용 때문에 안 맞는 줄은 그대로 둔다. 목표는 "대부분의 줄"이지 "모든 줄"이 아니다.
- 대본 파일에서는 마디 경계를 ` / `로 표시한다. TTS 입력·자막으로 넘길 때는 ` / `를 뺀다.
- 숫자·영문·기호는 **읽는 소리대로 한글로** 쓴다(`3개` → `세 개`, `AI` → `에이아이`). 음절을 셀 수 있고 TTS도 정확히 읽는다.
- 적용 범위: 에이전트가 **새로 쓰는** 내레이션·보충 내레이션·자막 문구. 사람이 실제로 말한 촬영본의 전사 결과는 운율에 맞추려고 고쳐 쓰지 않는다.
- 채널의 `채널기준.md`에 다른 말투·운율 규칙이 적혀 있으면 그쪽을 따른다.

## 손으로 세어 본 예

```
오늘은 / 우리 동네 / 숨은 맛집 / 가 볼게     3/4/4/3
냉장고에 / 남은 재료 / 이것만은 / 꼭 넣어     4/4/4/3
딱 하나만 / 기억하세요                       4/5
```

앞의 둘은 네 마디가 모두 3~4음절이라 `맞음`, 마지막은 5음절 마디가 하나 있어 `허용`이다. 둘 다 좋은 줄이다.

## 세어 주는 도구

```
python3 "<workspace>/도구/script/check_rhythm.py" "<대본 파일>"
python3 "<workspace>/도구/script/check_rhythm.py" "<대본 파일>" --strip
```

첫 명령은 줄마다 `3/4/4/3` 같은 패턴과 판정을 표로 보여 준다. 두 번째는 마디 표시 ` / `를 뺀 대본만 내놓는다 — TTS 원고와 자막에는 그것을 쓴다.

파일에 `## 대본` 제목이 있으면 그 아래 글만 세고 내놓는다(안내문·예시·메모는 건드리지 않는다). 제목이 없으면 파일 전체를 대본으로 본다. 채널의 `02_기획과자막/_양식/대본_양식.md`를 복사해 쓴 대본이 바로 이 경우다. 코드 블록과 `#`으로 시작하는 줄, 줄 앞의 목록 기호(`- `)는 어느 쪽에서든 뺀다.

**이 도구는 관문이 아니다.** 비율이 얼마든 종료 코드는 0이고, 판정은 "여기서 리듬이 처진다"는 표시일 뿐이다. 사람이 굳이 관문으로 쓰고 싶으면 `--min-rate 0.7`을 주면 된다. 사용자에게 비율을 합격선처럼 말하지 않는다.

판정은 세 가지다.

| 판정 | 뜻 |
|---|---|
| `맞음` | 두~네 마디이고 모든 마디가 3~4음절 |
| `허용` | 두~네 마디이고 모든 마디가 3~5음절, 그중 5음절이 하나 이상 |
| `벗어남` | 그 밖 (마디가 너무 많거나 적고, 2음절 이하·6음절 이상 마디가 있다) |

비율에서 빠지는 줄도 두 가지 있다. `마디 표시 없음`은 ` / `를 아직 안 붙인 줄이고, `읽는 대로 한글로 풀어 쓰세요`는 숫자·영문이 남아 있어 음절을 제대로 셀 수 없는 줄이다. 둘 다 틀린 줄이 아니라 아직 셀 수 없는 줄이므로 비율에 넣지 않는다.

## 벗어남을 고치는 법

| 증상 | 고치는 법 |
|---|---|
| 한 마디가 너무 길다(6음절 이상) | 뜻이 끊기는 자리에서 둘로 나눈다. `기억해 주세요`(6) → `기억해 / 주세요`(3/3) |
| 한 마디가 너무 짧다(1~2음절) | 옆 마디에 붙인다. `꼭 / 넣어 주세요` → `꼭 넣어 / 주세요` |
| 나눌 자리가 없다 | 같은 뜻의 다른 길이 낱말로 바꾼다. `구입했습니다` → `샀어요`, `굉장히` → `아주` |
| 마디가 다섯 이상이다 | 문장을 두 줄로 나눈다. 쇼츠 자막은 한 줄이 짧을수록 읽힌다 |

## 하지 않을 것

- **군말로 채우지 않는다.** `그런데`, `사실은`, `여러분` 같은 말을 음절 수를 맞추려고 넣지 않는다. 운율은 맞아도 대본이 늘어진다.
- **사실을 바꾸지 않는다.** 숫자·가격·이름·인용은 길이가 안 맞아도 그대로 둔다. 그런 줄은 `벗어남`으로 남겨 두는 것이 맞다.
- **사람이 한 말을 고쳐 쓰지 않는다.** 촬영본 전사 결과는 실제로 한 말이 원본이다. 운율에 맞추려고 문장을 다듬으면 자막이 화면의 말과 달라진다.
- **모든 줄을 맞추려 하지 않는다.** `맞음`이 100%인 대본은 대개 부자연스럽다. 소리 내어 읽었을 때 걸리는 데가 없으면 충분하다.
