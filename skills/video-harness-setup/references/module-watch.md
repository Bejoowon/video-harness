# watch 모듈

## 무엇을 설치하나

- 저장소 `https://github.com/bradautomates/claude-video`에서 영상 저장·분석 스킬을 설치한다. 실제 설치 명령은 `npx skills add bradautomates/claude-video -g`다(README에서 확인한 명령이며, `-g`는 전역 설치를 뜻한다. 빼면 지금 작업 공간에만 설치된다).
- 이 설치는 에이전트 자신의 스킬 폴더를 바꾸는 작업이므로 수동 확인 항목이다. 사용자에게 확인받은 뒤에만 실행한다.
- 설치 뒤 첫 실행에서 그 스킬 자체의 `setup.py --json` 사전 점검을 따른다(이 하네스가 만드는 파일이 아니라 watch 스킬 자체의 점검이다).
- `yt-dlp`가 없으면 설치 안내 명령이 추가로 붙는다.

## 사용자에게 알릴 것

- 필요한 도구: `yt-dlp`(영상 다운로드), `ffmpeg`(이미 하네스 필수 도구라 보통 이미 있다). Whisper API 키는 선택 사항(자막이 없을 때 대체 전사용)이다.
- 이 설치는 에이전트의 스킬 폴더 자체를 바꾼다. 반드시 사용자 확인을 받은 뒤에만 실행한다.
- 레퍼런스 영상의 다운로드·분석은 이 모듈이 설치돼 있고 사용자가 원할 때만 세팅 끝에 이어서 하고, 그렇지 않으면 제작 절차 단계(2단계)에서 진행한다.

## 설치 뒤 확인

- 설치 위치가 에이전트의 스킬 폴더라 작업 공간 안에서는 확인할 수 없다. `doctor.py`도 이 모듈만을 위한 항목을 두지 않는다. 스킬 목록에 나타나는지 사용자에게 직접 확인받는다.
- `yt-dlp` 설치 여부는 `doctor.py`가 확인하지 않는다(`doctor.py`의 도구 점검은 필수 도구만 본다). 대신 `python3 "${SKILL_DIR}/scripts/preflight.py" "<workspace>" --json`을 실행해 결과의 `tools.yt-dlp` 항목을 본다.

## 자주 막히는 곳

- `yt-dlp`가 없으면 다운로드 단계에서 실패한다. 안내된 설치 명령을 실행한 뒤 다시 시도한다.
- `-g`를 빼고 설치하면 지금 작업 공간에서만 보이고 다른 작업 공간에서는 다시 설치해야 할 수 있다.
- 저장소 README의 설치 명령이 이 문서와 달라졌다면, 실제로 접속해 README를 다시 확인하고 이 문서와 설치 단계를 함께 갱신한다.
