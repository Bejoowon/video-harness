# 출발점 — 영상을 만드는 두 가지 흐름

인터뷰의 첫 질문("직접 찍은 촬영본으로 만드시나요?")에 대한 배경이다. 사용자가 헷갈려 할 때, 그리고 뒤 단계의 추천을 정할 때 읽는다. 값은 채널의 `workflow`에 `footage-first` · `script-first` · `per-episode` 중 하나로 기록된다.

## 두 흐름을 나란히 놓으면

| | `footage-first` (찍은 영상 먼저) | `script-first` (대본 먼저) |
|---|---|---|
| 시작점 | 이미 찍어 둔 촬영본 | 하고 싶은 말 · 주제 |
| 순서 | 촬영본 확인 → 전사 → 쓸 구간 고르기 → 구성안 → 자막·보충 내레이션 → 샘플 → 본편 편집 | 주제 → 레퍼런스 분석 → 대본 → 목소리 → 소재 찾기·생성 → 샘플 → 본편 편집 |
| 자막의 원본 | **전사 결과**. 실제로 한 말을 받아 적은 것이 자막이 된다 | **대본**. 쓴 문장이 그대로 자막이 되고 목소리도 거기서 나온다 |
| 중요한 모듈 | 전사(필수) · 편집기 넘기기 · 소재는 `own-footage` | 목소리(TTS 또는 녹음) · 소재는 `stock`·`higgsfield` · 레퍼런스 분석 |
| 시간이 드는 곳 | 쓸 구간을 고르는 일. 촬영본이 길수록 오래 걸린다 | 대본을 쓰는 일과 대본에 맞는 화면을 구하는 일 |

`script-first`에서 쓰는 대본은 에이전트가 새로 쓰는 글이므로 작업 공간의 운율 규칙이 그대로 적용된다 — 읽었을 때 리듬이 느껴지게 마디를 ` / `로 나눠 쓴다(`script-rhythm.md`). `footage-first`에서도 촬영본 위에 얹는 **보충 내레이션**과 새로 쓰는 자막 문구는 같은 규칙을 따르지만, 실제로 한 말을 받아 적은 전사 결과는 운율에 맞추려고 고쳐 쓰지 않는다.

`per-episode`(회차마다 정함)는 세 번째 값이지만 제3의 흐름은 아니다. 회차를 시작할 때마다 "이번엔 촬영본이 있는가"를 먼저 확인해 위 둘 중 하나를 고르고, 고른 쪽을 회차 기록에 적는다. 그래서 세팅에서는 두 흐름에 필요한 모듈을 모두 안내하고 사용자가 고르게 한다.

## 초보자에게 설명하는 말

전문 용어를 빼고 이렇게 묻는다.

- **찍은 영상 먼저** — "핸드폰이나 카메라로 찍어 둔 영상이 있고, 그걸 보면서 쓸 부분을 골라 이야기를 만드는 방식이에요. 브이로그, 가게 소개, 현장 기록이 여기에 들어갑니다."
- **대본 먼저** — "할 말을 먼저 글로 쓰고, 거기에 맞는 화면을 찾거나 만들어 붙이는 방식이에요. 정보 전달, 이야기 들려주기, 목소리만 얹는 영상이 여기에 들어갑니다."

그래도 고르기 어려워하면 한 가지만 되묻는다: "지금 컴퓨터나 핸드폰에 쓸 만한 촬영본이 있나요?" 있으면 찍은 영상 먼저, 없으면 대본 먼저다. 매번 다르면 회차마다 정함이다.

## 중간 사례 — 찍은 영상에 새 내레이션을 얹는 경우

"찍어 둔 영상은 있는데 거기에 목소리를 새로 넣고 싶다"는 요청이 자주 나온다. 이것은 대부분 `footage-first`다. 순서의 출발점이 여전히 촬영본이고, 자막의 원본도 촬영본 전사이기 때문이다. 새로 넣는 목소리는 그 위에 얹는 **보충 내레이션**이고, 채널기준의 작업 순서에도 "필요하면 보충 내레이션"으로 들어 있다. 이때는 목소리 단계에서 `record`만 권하지 말고 TTS도 함께 설명한다. 보충 내레이션은 에이전트가 새로 쓰는 글이므로 운율 규칙을 적용한다(`script-rhythm.md`) — 같은 회차의 전사 자막은 그대로 둔다.

원래 소리를 아예 버리고 대본을 새로 쓴다면 `script-first`에 가깝다. 회차마다 달라진다면 `per-episode`로 적고, 회차를 시작할 때 고르게 한다.

## 이 답이 바꾸는 것

- 채널의 `채널기준.md`에 "출발점" 한 줄과 "작업 순서" 절이 이 값에서 만들어진다. 이미 만들어진 파일은 세팅 스크립트가 덮어쓰지 않으므로, 나중에 출발점을 바꾸면 그 절도 손으로 고친다.
- 작업 공간의 `AGENTS.md`는 고정된 순서를 정하지 않고 "그 채널의 `채널기준.md`에 있는 작업 순서를 따르라"고만 적는다.
- 영상 유형(`kind`)이 이 값에서 정해진다. `script-first`는 `narration-shorts`, 그 밖에는 세로면 `footage-shorts`, 가로면 `longform-vlog`다.
- 출발점이 비어 있는 채널은 점검에서 `주의`로 뜬다. 값을 채우려면 목록 번호를 짚어 기록한다.

```
python3 "${SKILL_DIR}/scripts/config_tool.py" set "<workspace>" channels.0.workflow footage-first
```
